# 行为树决策链路

本文档根据 `src/ats_sentry_behavior` 代码整理。

## 代码范围

`ats_sentry_behavior` 负责把比赛状态、机器人状态、视觉目标、导航反馈和 costmap 变成导航/云台/底盘模式输出。

目录职责：

- `behavior_trees/`：行为树 XML。
- `params/`：行为树参数。
- `plugins/action/`：行为树动作节点。
- `plugins/condition/`：行为树条件节点。
- `plugins/control/`：控制流节点。
- `plugins/decorator/`：装饰节点。
- `src/ats_sentry_behavior/src/ats_sentry_behavior_server.cpp`：行为树服务端。
- `src/ats_sentry_behavior/src/ats_sentry_behavior_client.cpp`：行为树客户端。

## 启动方式

入口：

```bash
ros2 launch ats_sentry_behavior ats_sentry_behavior_launch.py
```

启动节点：

- `ats_sentry_behavior_server`
- `ats_sentry_behavior_client`

参数文件默认：

- `src/ats_sentry_behavior/params/sentry_behavior.yaml`

loopback 使用：

- `src/ats_sentry_behavior/params/sentry_behavior_loopback.yaml`

视觉专测使用：

- `src/ats_sentry_behavior/params/sentry_behavior_decision_vision_test.yaml`

## 黑板输入

服务端订阅以下输入并写入 BehaviorTree 黑板。

裁判系统：

- `referee/event_data` -> `referee_eventData`
- `referee/all_robot_hp` -> `referee_allRobotHP`
- `referee/game_status` -> `referee_gameStatus`
- `referee/ground_robot_position` -> `referee_groundRobotPosition`
- `referee/rfid_status` -> `referee_rfidStatus`
- `referee/robot_status` -> `referee_robotStatus`
- `referee/buff` -> `referee_buff`

视觉：

- `vision/target` -> `sp_vision_target`

导航和地图：

- `global_costmap/costmap` -> `nav_globalCostmap`
- `odom` 或 `odometry` -> `decision_current_pose`

仿真决策：

- `decision/sim_mode` -> `decision_sim_mode`

## 决策输入源

参数 `decision.input_source` 支持：

- `referee`
- `simulation`

当输入源为 `simulation` 时，服务端会从 `decision.simulation.mode_topic` 读取模式。支持的仿真模式：

- `patrol`
- `anchor`
- `retreat`
- `safe`

## 行为树文件

当前行为树文件包括：

- `rmul_2025.xml`
- `rmul_2026.xml`
- `rmuc_2026_mapping.xml`
- `rmuc_2026_no_referee_test.xml`
- `rmuc_2026_patrol_only.xml`
- `decision_vision_test.xml`
- `dev_rm.xml`
- `models.xml`

行为树文件只定义决策结构。具体动作和条件由 C++ 插件实现。

## 动作节点范围

`plugins/action` 中的主要节点：

- `LoadCsvWaypoints`：加载 CSV 点位。
- `SelectPatrolPath`：选择巡逻路径。
- `AdvancePatrolCursor`：推进巡逻游标。
- `SelectSupplyPoint`：选择补给点。
- `SelectNearestRetreatPath`：选择最近退防点。
- `SelectFixedPath`：选择固定路径。
- `SelectPathGoalPose`：从路径中提取目标点。
- `SelectVisionFollowPath`：根据视觉目标和 costmap 生成视觉跟随点。
- `PublishDecisionGoal`：发布决策目标。
- `PubNav2Goal`：发布 Nav2 goal。
- `SendNav2Goal`：发送 NavigateToPose。
- `SendNavThroughPoses`：发送 NavigateThroughPoses。
- `PubTwist`：发布 Twist。
- `PubSpinSpeed`：发布自旋速度。
- `PubGimbalAbsolute` / `PubGimbalVelocity`：发布云台指令。
- `PubRobotMode`：发布姿态模式。
- `HoldStopFlag`：发布 stop flag。
- `ResetLowHpTarget`：重置低血量目标。

## 条件节点范围

`plugins/condition` 中的主要节点：

- `IsGameStatus`：判断比赛阶段。
- `IsGameTimeStage`：按剩余时间划分阶段。
- `IsHpBand`：按血量阈值划分状态。
- `IsRobotHpBelow`：判断血量是否低于阈值。
- `IsRobotResourceMode`：判断资源策略状态。
- `IsRobotResupplyRequired`：判断是否需要补给。
- `IsAttacked`：判断是否受击。
- `IsRfidDetected`：判断 RFID。
- `IsFriendlyOutpostDestroyed`：判断己方前哨站状态。
- `IsVisionTargetValid`：判断视觉目标是否可用。
- `IsPathGoalReached`：判断路径目标是否到达。
- `IsDecisionInputSource`：判断当前输入源。
- `IsDecisionMode`：判断仿真决策模式。
- `IsStatusOK`：判断机器人状态有效。

## 输出话题

行为树输出：

- `cmd_spin`：自旋速度，供 `fake_vel_transform` 叠加角速度。
- `cmd_vel`：直接 Twist 输出节点使用。
- `cmd_gimbal`：云台控制，供 `gimbal_manager` 转成 joint state。
- `decision/robot_mode`：姿态模式，供 `standard_robot_pp_ros2` 写入下位机速度模式字段。
- Nav2 action：
  - `/navigate_through_poses`
  - `/navigate_to_pose`

## 视觉跟随策略

视觉链路输入消息为 `sp_msgs/msg/VisionTargetMsg`。行为树服务端参数中 `decision.vision.*` 控制视觉接管：

- `timeout_s`：视觉消息新鲜度。
- `attack_radius`：目标周围跟随半径。
- `follow_occupied_threshold`：costmap 占用阈值。
- `follow_sample_count`：圆周采样数量。
- `follow_arc_half_angle_deg`：采样弧范围。
- `min_replan_interval_s`：最小重规划间隔。
- `min_goal_shift_m`：目标变化阈值。
- `activation_hold_s`：首次接管保持时间。
- `switch_target_hold_s`：切换目标保持时间。
- `override_hold_s`：短时丢帧接管保持。
- `visualization_topic`：视觉跟随 marker 话题。

`SelectVisionFollowPath` 会结合目标地图坐标、当前机器人位姿和 costmap，选择可通行跟随点，并发布可视化 marker。

## 资源策略

资源策略参数位于 `decision.resource_policy.*`：

- `defend_enter_hp`
- `defend_exit_hp`
- `resupply_enter_hp`
- `resupply_exit_hp`
- `resupply_enter_ammo`
- `resupply_exit_ammo`
- `assume_engage_when_status_missing`
- `require_valid_ammo_before_resupply`

策略输出用于决定是否允许继续巡逻/追击、是否回补给点、是否进入防守状态。
