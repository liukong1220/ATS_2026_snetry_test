# 启动入口与运行链路

本文档根据 `src` 中 launch 文件和参数文件整理。

## 实机总入口

入口：

```bash
ros2 launch ats_sentry_bringup bringup.launch.py world:=rmuc_2025 slam:=False use_rviz:=True
```

对应文件：

- `src/ats_sentry_bringup/launch/bringup.launch.py`
- `src/ats_sentry_bringup/params/node_params.yaml`
- `src/ats_sentry_bringup/map/<world>.yaml`
- `src/ats_sentry_bringup/pcd/<world>.pcd`

`world` 同时用于拼接地图和 PCD：

```text
map:       src/ats_sentry_bringup/map/<world>.yaml
prior_pcd: src/ats_sentry_bringup/pcd/<world>.pcd
```

注意：PCD 文件本地存在即可，`*.pcd` 不提交到 Git。

`bringup.launch.py` 组合以下模块：

- `standard_robot_pp_ros2.launch.py`：串口桥和云台管理。
- `sentry_chassis_vel_transform/chassis_vel_transform_node`：速度从云台大 yaw 坐标转底盘 `/cmd_vel`。
- `ats_nav_bringup/rm_navigation_reality_launch.py`：实机导航。
- `ats_sentry_behavior_launch.py`：行为树服务端和客户端。
- `rviz_launch.py`：可选 RViz。
- `record_rosbag_launch.py`：可选 rosbag 录制。

关键 launch 参数：

- `robot_name`：机器人描述名，默认 `ats_sentry_robot`。
- `slam`：是否启用 SLAM。为 `True` 时 small_gicp 被关闭，并使用静态 `map -> odom`。
- `world`：地图和 PCD 基名。
- `namespace`：顶层 namespace。
- `use_sim_time`：是否使用仿真时间。
- `params_file`：默认 `ats_sentry_bringup/params/node_params.yaml`。
- `behavior_params_file`：默认 `ats_sentry_behavior/params/sentry_behavior.yaml`。
- `use_robot_state_pub`：是否由 robot_state_publisher 提供机器人 TF。
- `launch_joy_teleop`：是否启动手柄遥控。
- `launch_rosbag_recorder`：是否启动录包。
- `launch_trajectory_optimizer`：是否启动旁路轨迹可视化优化器。
- `launch_small_gicp_relocalization`：是否启动 small_gicp 重定位。

## 实车 Nav2-free 自研链入口（P6 零.1）

入口：

```bash
ros2 launch ats_sentry_bringup real_robot_nav2_free.launch.py world:=rmuc_2026
```

对应文件：`src/ats_sentry_bringup/launch/real_robot_nav2_free.launch.py`。

该入口与上面的 Nav2 对照 profile **互斥**，它把下列参数钉死，不接受覆盖：

| 参数 | 钉死值 | 理由 |
| --- | --- | --- |
| `launch_nav2` | `false` | 运行图中不出现任何 Nav2 节点、任何 lifecycle manager，也不存在 `/plan` 的生产者或消费者 |
| `launch_swerve_mpc` | `true` | 自研链只在 `launch_swerve_mpc=true` 且 `launch_nav2=false` 时成立 |
| `launch_minco_planner` | `true` | JPS + MINCO S3 是唯一轨迹来源 |
| `launch_goal_manager` | `true` | `/planner/execution_command` 的唯一生产者 |
| `launch_fake_vel_transform` | `false` | 禁止在 MPC 之后叠加 `cmd_spin` 角速度 |
| `launch_chassis_vel_transform` | `false` | 禁止在 MPC 之后二次旋转或增益放大 `[vx, vy, wz]` |
| `mpc_cmd_vel_topic` | `/cmd_vel` | MPC 直接产出车体系 `/cmd_vel`，串口桥直接消费 |
| `use_sim_time` | `False` | 实车必须用系统时钟，否则 `0.5 s` 租约与 stale 判据全部失效 |

命令通路（唯一）：

```text
MPC -> /cmd_vel -> standard_robot_pp_ros2 -> speed_vector {vx, vy, wz}
```

Nav2 对照 profile 的通路保持原样，两级变换由 `navigation_launch.py` 中
`fake_vel_transform_enabled` / `chassis_vel_transform_enabled` 的
`and launch_nav2 == 'true'` 条件保证只在 Nav2 下存在。

`gimbal_yaw_odom -> gimbal_yaw_fake` 零旋转兼容 TF 由
`UnlessCondition(fake_vel_transform_enabled)` 提供，因此每个 profile 各有唯一所有者，
不会出现两个发布者。

云台反馈：实车 `GimbalYawStatus` 由 `gimbal_yaw_status_bridge_node` 从串口云台关节反馈产出。
若在受控 HIL profile 下把 `require_gimbal_status` 置为 `false`，则
`BODY_YAW_FOLLOW` 被禁止，不得以任何方式伪造 ack。

### 抬轮 HIL profile

抬轮 HIL（执行器断开，四轮离地）在上面的入口上再加两个参数：

```bash
ros2 launch ats_sentry_bringup real_robot_nav2_free.launch.py \
  launch_behavior:=False \
  require_gimbal_status:=False
```

| 参数 | HIL 取值 | 理由 |
| --- | --- | --- |
| `launch_behavior` | `False` | 行为树会自己下发导航目标。它在跑的时候，五级归零的实测时延无法归因到某一次授权跳变，因此 HIL 期间授权只能由测试脚本单独触发 |
| `require_gimbal_status` | 按云台是否通电取值 | 云台未通电时置 `False`，此时 `BODY_YAW_FOLLOW` 被禁止；禁止伪造 ack |

`launch_behavior` 默认 `True`，正式实车运行不需要显式给出。此前
`start_behavior_launch_cmd` 是无条件加入 `LaunchDescription` 的，
即没有任何办法在不改代码的情况下关掉行为树。

## 导航入口

`ats_nav_bringup/launch/bringup_launch.py` 是导航域的核心组合入口。它再拆成：

- `localization_launch.py`
- `navigation_launch.py`
- `slam_launch.py`

`bringup_launch.py` 的主要参数：

- `map`：地图 YAML。
- `prior_pcd_file`：PCD 地图。
- `params_file`：Nav2 参数。
- `launch_small_gicp_relocalization`：是否启动 PCD 重定位。
- `launch_chassis_vel_transform`：是否启动底盘速度转换。
- `launch_trajectory_optimizer`：是否启动旁路轨迹优化器。
- `use_composition`：是否使用 component container。

定位入口 `localization_launch.py` 启动：

- `point_lio/pointlio_mapping`
- `nav2_map_server`
- `small_gicp_relocalization_node`
- `nav2_lifecycle_manager`

导航入口 `navigation_launch.py` 启动：

- `terrain_analysis`
- `terrain_analysis_ext`
- `loam_interface`
- `sensor_scan_generation`
- `fake_vel_transform`
- `trajectory_optimizer_node`
- `trajectory_speed_governor_node`
- Nav2 的 controller、planner、smoother、bt_navigator、behavior_server、waypoint_follower、velocity_smoother
- 可选 `sentry_chassis_vel_transform`

## 行为树入口

入口：

```bash
ros2 launch ats_sentry_behavior ats_sentry_behavior_launch.py
```

对应文件：

- `src/ats_sentry_behavior/launch/ats_sentry_behavior_launch.py`
- `src/ats_sentry_behavior/params/sentry_behavior.yaml`
- `src/ats_sentry_behavior/behavior_trees/*.xml`

启动节点：

- `ats_sentry_behavior_server`
- `ats_sentry_behavior_client`

服务端订阅裁判系统、视觉目标、costmap、odom，并写入行为树黑板。客户端按参数中的目标树向服务端发送执行请求。

## loopback 决策仿真入口

入口：

```bash
ros2 launch ats_sentry_bringup loopback_decision_sim.launch.py use_rviz:=True
```

代码范围：

- `src/ats_sentry_bringup/launch/loopback_decision_sim.launch.py`
- `src/sim/loopback_sim/launch/bringup_launch.py`
- `src/sim/loopback_sim/launch/loopback_simulation.launch.py`
- `src/ats_sentry_bringup/scripts/fake_decision_sim_inputs.py`

该入口组合：

- Nav2 loopback bringup。
- loopback simulator。
- 行为树。
- fake decision inputs。
- 可选 RViz。

fake 输入脚本可发布：

- `/initialpose`
- `decision/sim_mode`
- `vision/target`
- `vision/target_point_map`
- `referee/game_status`
- `referee/robot_status`
- `referee/rfid_status`

## loopback 纯导航入口

入口：

```bash
ros2 launch ats_sentry_bringup loopback_nav_only.launch.py use_rviz:=True
```

该入口用于只观察 Nav2、轨迹平滑、速度治理和恢复行为，不启动完整行为树决策。

## MuJoCo 导航入口

入口：

```bash
ros2 launch ats_mujoco_sim mujoco_navigation.launch.py
```

对应文件：

- `src/sim/ats_mujoco_sim/launch/mujoco_navigation.launch.py`
- `src/sim/ats_mujoco_sim/launch/ats_mujoco_sim.launch.py`
- `src/sim/ats_mujoco_sim/ats_mujoco_sim/twist_to_motion_ctrl.py`

`mujoco_navigation.launch.py` 会启动：

- MuJoCo 仿真节点。
- `nav2_map_server`。
- 可选 Nav2。
- `twist_to_motion_ctrl` 桥，把 `Twist` 转为 `manda_can_control/MotionCtrl`。
- 可选 RViz。

后续完整仿真测试统一使用 MuJoCo。Gazebo 联调入口和依赖已清理；需要快速验证行为树或 Nav2 话题链时使用 loopback。

## RViz 与 rosbag

RViz 统一入口：

- `src/ats_sentry_bringup/launch/rviz_launch.py`
- `src/ats_sentry_bringup/rviz/sentry_default_view.rviz`

rosbag 入口：

- `src/ats_sentry_bringup/launch/record_rosbag_launch.py`
- `src/tools/rosbag2_composable_recorder/launch/recorder.launch.py`

录制话题列表来自 `src/ats_sentry_bringup/params/node_params.yaml` 的 `rosbag_recorder.ros__parameters.topics`。
