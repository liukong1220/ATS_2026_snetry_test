# 视觉与串口桥说明

## 简介

视觉/裁判系统提供任务输入，串口桥消费唯一底盘速度；它们不替代定位、地图或导航 owner。

## 模块

视觉与裁判输入位于根业务包，`standard_robot_pp_ros2` 与仿真 `twist_to_motion_ctrl` 是速度下游。

## 依赖

ROS 2、业务消息接口、串口硬件依赖和底盘协议。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --parallel-workers 1
```

## 启动

根 bringup 负责串口、云台状态、fake-yaw/chassis transform 兼容层与行为输入编排。

## 接口

MPC 输出车体系 `[vx, vy, wz]`。MuJoCo 中唯一通路是
`/cmd_vel_mpc -> twist_to_motion_ctrl -> /motion_control`；实机不得新增 `/cmd_vel` 或
`/motion_control` 第二 owner。

## 配置

串口/transform 参数在根总 YAML；实机默认保留 fake-yaw 与 chassis transform，关闭时必须保持
frame、TF 和速度契约。

## 架构

```text
vision/referee -> behavior -> Goal Manager -> MPC -> speed bridge -> chassis
```

## 验证与限制

MuJoCo 已确认四舵轮最终 RPM 和速度归零；实机串口、云台和固定雷达迁移尚未验证。
