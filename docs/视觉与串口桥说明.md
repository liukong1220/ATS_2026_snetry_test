# 视觉与串口桥说明

本文档根据 `src/sp_vision25` 和 `src/standard_robot_pp_ros2` 中的源码整理。

## 视觉域 `sp_vision25`

包路径：

- `src/sp_vision25`

ROS 包名：

- `sp_vision25`

代码范围：

- `src/`：不同机器人/调试入口主程序。
- `tasks/auto_aim`：装甲板检测、分类、解算、跟踪、自瞄规划。
- `tasks/auto_buff`：能量机关相关逻辑。
- `tasks/omniperception`：全向感知决策相关逻辑。
- `io/`：相机、云台、串口/SocketCAN、ROS2 适配。
- `configs/`：视觉配置。
- `assets/`：模型和布局文件。

## 哨兵视觉主程序

入口源码：

- `src/sp_vision25/src/sentry.cpp`

主流程：

```text
Camera 读取图像
Gimbal 提供姿态
YOLO 检测装甲板
Decider 过滤无敌目标并设置优先级
Tracker 跟踪目标
Planner 计算云台控制和开火建议
Gimbal 下发云台/开火控制
Decider 生成 VisionTargetState
ROS2 发布 vision/target
```

当前 `sentry.cpp` 中全向感知 fallback 初始化被关闭。tracker lost 时直接停止云台控制，不启动侧向 / 后向相机。

## 视觉到导航的发布

源码：

- `src/sp_vision25/io/ros2/publish2nav.cpp`
- `src/sp_vision25/io/ros2/vision_target.hpp`

发布节点：

- `vision_target_publisher`

发布话题：

- `vision/target`：`sp_msgs/msg/VisionTargetMsg`
- `vision/target_point_map`：`geometry_msgs/msg/PointStamped`

`VisionTargetState` 字段：

- `tracking`
- `nav_hold`
- `fire_permitted`
- `target_id`
- `confidence`
- `target_distance`
- `target_yaw`
- `target_pitch`
- `target_position_gimbal`
- `target_position_map`
- `has_target_position_map`
- `target_position_map_frame`
- `observation_time`

`Publish2Nav` 会根据配置读取坐标系和外参：

- `map_frame`
- `camera_frame`
- `mount_frame`
- `gimbal_frame`
- `calib_gimbal_frame`
- `pose_timeout_s`
- `transform_timeout_s`
- `nav_hold_min_confidence`
- `publish_target_point_map`
- `publish_calib_tf`
- `R_camera2gimbal`
- `t_camera2gimbal`

当视觉没有直接提供地图点时，`Publish2Nav` 会尝试通过 TF 将云台坐标系下目标点投影到地图坐标系。只有在 `tracking`、地图点有效、置信度满足阈值时，`nav_hold` 才会继续传给行为树。

## 导航到视觉的订阅

源码：

- `src/sp_vision25/io/ros2/subscribe2nav.cpp`

节点：

- `nav_subscriber`

订阅：

- `enemy_status`：`sp_msgs/msg/EnemyStatusMsg`
- `autoaim_target`：`sp_msgs/msg/AutoaimTargetMsg`

功能：

- 维护最近的无敌目标列表。
- 维护导航/决策指定的优先目标。
- 收到两次后开启 1500ms 的空闲清理定时器，避免旧目标长期残留。

## `standard_robot_pp_ros2_node`

源码：

- `src/standard_robot_pp_ros2/src/standard_robot_pp_ros2.cpp`

职责：

- 打开并维护串口。
- 接收下位机和裁判系统数据。
- 发布 IMU、云台 joint、裁判系统、机器人状态。
- 订阅上层速度、云台、射击、姿态模式和 stop flag。
- 将上层命令写入下位机协议结构。

发布：

- `serial/imu`
- `serial/robot_state_info`
- `serial/gimbal_joint_state`
- `serial/robot_motion`
- `referee/event_data`
- `referee/all_robot_hp`
- `referee/game_status`
- `referee/ground_robot_position`
- `referee/rfid_status`
- `referee/robot_status`
- `referee/buff`
- `serial/debug/<name>`

订阅：

- `stop_flag`
- `/cmd_vel`
- `cmd_gimbal_joint`
- `cmd_shoot`
- `decision/robot_mode`

关键参数：

- `device_name`
- `baud_rate`
- `flow_control`
- `parity`
- `stop_bits`
- `record_rosbag`
- `set_detector_color`
- `debug`
- `publish_imu_as_gimbal_joint_state`
- `accept_legacy_two_axis_joint_state`
- `small_yaw_is_relative`

- `enable_transient_zero_cmd_hold`
- `transient_zero_cmd_hold_timeout_ms`
- `cmd_vel_watchdog_timeout_ms`
- `robot_mode_topic`

## `gimbal_manager_node`

源码：

- `src/standard_robot_pp_ros2/src/gimbal_manager.cpp`

职责：

- 订阅 `cmd_gimbal`。
- 支持绝对角控制和速度控制。
- 以 10ms 周期积分云台 pitch / yaw。
- 发布 `cmd_gimbal_joint`，供串口桥下发。

话题：

```text
ats_sentry_behavior 或其他上层
  -> cmd_gimbal
  -> gimbal_manager
  -> cmd_gimbal_joint
  -> standard_robot_pp_ros2_node
```

## 视觉、行为树、串口桥协作

```text
sp_vision25
  -> vision/target
  -> ats_sentry_behavior
  -> cmd_gimbal / decision/robot_mode / Nav2 action
  -> gimbal_manager / standard_robot_pp_ros2 / Nav2
```

```text
standard_robot_pp_ros2
  -> referee/*
  -> ats_sentry_behavior
  -> resource policy / posture mode / navigation goal
```

姿态模式由行为树发布到 `decision/robot_mode`，串口桥订阅后写入下位机速度模式字段。代码中的模式名映射为：

- `1`：attack
- `2`：defend
- `3`：move
