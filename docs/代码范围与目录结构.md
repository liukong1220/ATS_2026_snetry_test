# 代码范围与目录结构

## 简介

活动源码只在 `src`；根、导航和 MuJoCo 为独立 Git 仓库。

## 模块

- 根：`src/ats_sentry_bringup`、根脚本和本文档。
- 导航：`src/ats_sentry_nav` 的 ROGMap、RC-ESDF、MINCO、Goal Manager、MPC 和 launch。
- 仿真：`src/sim/ats_mujoco_sim` 的物理模型、bridge、场景和 RViz。

## 依赖

依赖通过 ROS package manifest 解析；`参考/` 仅作算法/许可证溯源。

## 构建

使用 `colcon build --base-paths src`，不扫描参考目录。

## 启动

入口由根 bringup、导航 bringup 和 MuJoCo RMUC2026 launch 组成。

## 接口

跨域接口以 ROS `.msg/.srv/.action` 为准，YAML 仅承载参数。

## 配置

`node_params.yaml` 是正式导航总 YAML；资产、设备与 HIL 开关由 launch 受控覆盖。

## 架构

```text
root assets/config -> nav algorithms -> MuJoCo or chassis bridge
```

## 验证与限制

提交前逐仓检查状态，显式 stage 文件，建议避免 `git add .`/`git add -A`；未知文件属于用户。
