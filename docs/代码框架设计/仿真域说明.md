# 仿真域说明

## 简介

MuJoCo 与 Gazebo 都接入自研导航算法；MuJoCo 适合确定性控制回归，Gazebo 适合验证 ROS/Gazebo 传感器、TF、重定位和底盘桥接口。loopback 仅用于轻量栅格和行为回归。

## 模块

- `ats_mujoco_sim`：传感器、静态地图、ATS action 与内部速度适配。
- `loopback_sim`：简化运动学与 ray/grid 测试，不替代完整导航闭环。
- `gazebo_simulator`：Gazebo 世界、真值/雷达桥、重定位接线和 `MotionCtrl` 底盘执行适配。

## 依赖

ROS 2 Humble、MuJoCo、活动导航包和根 `node_params.yaml`。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --packages-select ats_mujoco_sim \
  --symlink-install --parallel-workers 1
```

## 启动

每例使用新的 domain、无 viewer 和新的 MuJoCo 进程：

```bash
ROS_DOMAIN_ID=231 PLANNING_GRID_OWNER=rog_map \
  scripts/test_mujoco_minco_mpc_chain.sh
```

Gazebo 导航入口为 `rmu_gazebo_simulator/ats_gazebo_nav.launch.py`。接口账本、frame、QoS、唯一所有者和日志策略见 [Gazebo 与当前导航接口](Gazebo与当前导航接口.md)。

## 接口

MuJoCo 发布定位与点云；`ats_swerve_mpc` 唯一发布 `/cmd_vel/autonomy_raw`，arbiter 唯一发布
`/cmd_vel/selected`，`twist_to_motion_ctrl` 才能订阅 selected。Gazebo 的 `gz_chassis_cmd_adapter`
同时发布 `MotionCtrl` 和 Gazebo chassis Twist。仿真内部速度适配仅用于驱动模型，
不以轮速、接触或底盘反馈判定导航通过。

## 配置

`rmuc_2025_mujoco.launch.py` 启动静态地图、ROGMap、adapter、MINCO、Goal Manager、MPC、arbiter 和 bridge。
地图由 static map publisher 提供，不启动地图 lifecycle 管理器。默认 RViz 为 ROGMap/MINCO/MPC
诊断视图，未知层默认可关闭，ESDF 仅调试显示。

RMUC 2025 仿真 profile 当前关闭 `ats_rog_map_adapter.esdf_cloud_topic`。录屏中墙体周边的棕色带
来自 ESDF 调试点云的足迹禁入带/地形风险颜色编码，不是 MuJoCo 的高度碰撞体；关闭该调试发布后，
不会再把可通行区域绘成棕色，同时保留 `/rc_esdf/planning_grid`、数值 ESDF 和墙体碰撞。MuJoCo
自身的 heightfield 仍作为轮胎支撑几何保留，不能把调试颜色误判成物理障碍。

为改善转角跟踪，RMUC profile 在 `ats_swerve_mpc` 节点覆盖
`control_delta_weight=[0.70,0.70,0.60]`、`max_awz=2.0 rad/s^2`，并将 MINCO 参考的
`yaw_acceleration_limit` 同步为 `2.0 rad/s^2`。这会抑制偏航指令增量和
角加速度峰值；20 Hz 控制周期、轮速/舵角速率硬约束和安全急停契约不变。该组参数只在 MuJoCo
profile 生效，实车仍使用根 `node_params.yaml`，需要以转角误差、峰值角速度和饱和次数实测确认改善。

## 架构

```text
simulated sensor -> localization/scan -> ROGMap adapter -> MINCO -> Goal Manager
                 -> MPC -> /cmd_vel/autonomy_raw -> arbiter -> /cmd_vel/selected -> /motion_control
```

## 验证与限制

历史 revision 曾完成 rectangle、red_box 和九项 P2/P3 fault；rectangle/red_box 的历史终点误差分别为
`0.004126 m`/`0.003696 m`。这些记录只说明当时的导航算法运行，不能替代当前 revision 的准入。

当前 revision 的 2026-08-21 MuJoCo red_box 在 domain `207` 未完成第一个目标：ROGMap 数值投影、
规划网格唯一 owner、JPS/MINCO/MPC 和 `/cmd_vel_mpc` 单发布者已实际观测，但 Goal Manager 随后收到
`pose=(nan, nan)` 并进入 fail-stop。该运行不构成 red_box、P2 或 P3 通过证据；后续应定位无效定位/TF
状态的首次产生点，建议避免以仿真内部速度适配、轮速或接触 telemetry 作为替代条件。该 topic 是迁移前
历史记录；当前 revision 仍建议用 `/cmd_vel/selected` 重跑。
