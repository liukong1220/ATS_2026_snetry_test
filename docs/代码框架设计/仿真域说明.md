# 仿真域说明

## 简介

MuJoCo 与 Gazebo 都接入自研导航算法；MuJoCo 适合确定性控制与隧道 yaw 回归，Gazebo 适合验证 ROS/Gazebo 传感器、TF、重定位、底盘桥和与 MuJoCo 同风格的 RViz 接口。loopback 仅用于轻量栅格和行为回归。

## 模块

- `ats_mujoco_sim`：传感器、静态地图、RMUC 2027 隧道顶板、ATS action 与内部速度适配。
- `loopback_sim`：简化运动学与 ray/grid 测试，不替代完整导航闭环。
- `gazebo_simulator`：Gazebo 世界、RMUC 2027 model/roof、真值/雷达桥、重定位接线、`MotionCtrl` 底盘执行适配和 `ats_gazebo_nav.rviz`。

## 依赖

ROS 2 Humble、MuJoCo、活动导航包和根 `node_params.yaml`。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --packages-select ats_mujoco_sim \
  --symlink-install --parallel-workers 1
```

## 启动

每例使用新的 domain、无 viewer 和新的 MuJoCo 进程：

```bash
ROS_DOMAIN_ID=231 PLANNING_GRID_OWNER=rog_map \
  scripts/test_mujoco_minco_mpc_chain.sh
```

Gazebo 导航入口为 `rmu_gazebo_simulator/ats_gazebo_nav.launch.py`。接口账本、frame、QoS、唯一所有者和日志策略见 [Gazebo 与当前导航接口](Gazebo与当前导航接口.md)。

## 接口

MuJoCo 发布定位与点云；`ats_swerve_mpc` 唯一发布 `/cmd_vel/autonomy_raw`，arbiter 唯一发布
`/cmd_vel/selected`，`twist_to_motion_ctrl` 才能订阅 selected。Gazebo 的 `gz_chassis_cmd_adapter`
同时发布 `MotionCtrl` 和 Gazebo chassis Twist。仿真内部速度适配仅用于驱动模型，
不以轮速、接触或底盘反馈判定导航通过。

## 配置

`rmuc_2027_mujoco.launch.py` 启动 2027 静态地图、ROGMap、adapter、MINCO、Goal Manager、MPC、arbiter 和 bridge；隧道定义在 `config/tunnels_2027.yaml`，顶板碰撞体在 `models/rmuc_2027_roof_boxes.xml`。
地图由 static map publisher 提供，不启动地图 lifecycle 管理器。默认 RViz 为 ROGMap/MINCO/MPC
诊断视图，未知层默认可关闭，ESDF 仅调试显示。

RMUC MuJoCo 主场景源文件已直接移除 `rmuc_2025_wall_boxes.xml` include，因此不再加载原先的棕色
半透明高墙；`rmuc_2025_height.png` 对应的 heightfield 仍保留，继续作为轮胎支撑地形。
`enable_static_walls` 参数保留用于兼容通用场景和旧启动接口，但对当前 RMUC 主场景没有恢复墙体的作用。
`/map` 仍由静态地图独立发布，可能继续包含 occupied 单元；规划地图语义与 MuJoCo 物理场景需分别验证，
不能仅依据物理场景无墙推断规划器不会绕行这些 occupied 单元。

转角跟踪的 MuJoCo 回归参数已收紧：MPC `control_delta_weight=[0.70,0.70,0.60]`、
`max_awz=2.0`，MINCO `yaw_acceleration_limit=2.0`。这些参数用于减少相邻周期 `wz`
突变；在完整红框闭环重新运行前只标记为“已实现未完成闭环验证”。

仿真、规划器和重定位节点的人类可读日志统一使用中文；周期性状态采用已有节流宏或固定摘要周期，
不在每个传感器/控制周期刷屏。topic、frame、generation、TRACE 键和结构化字段保持原契约。

## 架构

```text
simulated sensor -> localization/scan -> ROGMap adapter -> MINCO -> Goal Manager
                 -> MPC -> /cmd_vel/autonomy_raw -> arbiter -> /cmd_vel/selected -> /motion_control
```

## 验证与限制

MuJoCo 完整 pytest 为 `53 passed`；`tunnel_B` 已进入并通过，隧道内最大 yaw 误差约 `4.9e-12`，终点误差 `0.0`。导航隧道 yaw 相关 CTest 为 `3/3`。Gazebo 2027 world/SDF、模型、依赖和 RViz 配置通过静态/启动检查，但当前运行日志出现 `libEGL ... failed to create dri2 screen`，`/registered_scan` 无消息，故完整 Gazebo 导航闭环仍被环境阻断。物理接触 evaluator、实车/HIL、P3/P4 仍未验证。
