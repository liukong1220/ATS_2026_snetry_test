# 仿真域说明

## 活动入口与边界

当前导航验收使用 `src/sim/ats_mujoco_sim` 的 RMUC 2027 场景（`rmuc_2027_mujoco.launch.py`，默认有图 `slam:=false`、`solver_mode:=qp`）。场景、路线、起点与命令以 [2027 导航验证方案](../nav_acceptance/20261116_2027_final_test_plan.md) 为准；RMUL 3V3 与 Gazebo 见各自说明，不替代 RMUC 2027 主套件。

MuJoCo 提供四舵轮物理、传感器与独立真值 `/simulation/ground_truth/odometry`；正式验收统一使用 `localization_source:=lio`（Point-LIO + 地图匹配），不以真值定位替代 LIO。

## 构建与运行

```bash
./build.sh --packages-select ats_mujoco_sim
```

运行前核验同域无残留进程，选择独立 `ROS_DOMAIN_ID` 与新输出目录，默认无窗口（`USE_RVIZ=false USE_MUJOCO_VIEWER=false`）运行 `scripts/s3_mujoco_acceptance.py`（支持 `tunnel_b_roundtrip`、`ramp_south`、`six_tunnels`、`base_to_base`、`symmetry_speed`、`b2_detour` 及 5 项独立故障；无先验建图加 `--mapless`）。

## 传感器、渲染与性能

| 项目 | 当前契约 |
| --- | --- |
| LiDAR | MID360，仿真时间 `10 Hz`、最多 `20,000` 射线/帧（`<=5 ms` 分段带 `offset_time`）；`mjlidar_cpu.py` 支持静态场网格 + 解析几何体快速路径，保持同组实体箱可见 |
| IMU / 物理 | LIO 模式 `200 Hz` / `400 Hz` |
| 视图同步 | `sim_node.py` 在 `sim_lock` 内仅拷贝 `mjSTATE_INTEGRATION`，将 `mj_forward` 与 `viewer.sync()` 移出锁外（默认 `viewer_rate_hz=15.0`） |
| 车体与轮速 | 长×宽 `0.581 × 0.571 m`、余量 `0.02 m`、车高门 `0.249 m`、终端容差 `0.05 m`；平移上限 `5 m/s`、yaw `3 rad/s`、轮速控制范围 `±117.647 rad/s`（轮半径 `0.0425 m`） |
| RViz 配置 | `rviz/mujoco_navigation.rviz` 深色高对比背景，显示车模、定位/真值箭头、`/goal_pose` 箭头、当前帧 `/registered_scan`、传感器轴与局部规划窗口组 |

## 所有权链路

```text
Point-LIO/fusion -> ROGMap 进程内 adapter -> PlanningMapSnapshot
 -> 混合搜索/MINCO -> Goal Manager -> OSQP SQP-RTI MPC (/cmd_vel/autonomy_raw)
 -> arbiter (/cmd_vel/selected) -> twist_to_motion_ctrl (/motion_control) -> MuJoCo
```

每一级唯一发布者与急停零输出均由 runner 断言；当前尚未实现 geom-pair 级独立接触评估器，故 `physical_contact_acceptance` 记为 `unverified`。
