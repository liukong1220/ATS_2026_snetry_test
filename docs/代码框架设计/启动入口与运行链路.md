# 启动入口与运行链路

## 简介

正式导航使用 ATS 自研定位融合、ROGMap、MINCO、Goal Manager 与唯一 `OSQP SQP-RTI` MPC。所有生产入口均不启动 Nav2 server，不使用 `/plan`。

## 模块

- 根入口：`src/ats_sentry_bringup/launch/bringup.launch.py`（默认 `lidar_mount_mode:="chassis"`）。
- 实机入口：`src/ats_sentry_bringup/launch/real_robot_navigation.launch.py`（默认 `lidar_mount_mode:="gimbal"`、`gimbal_use_base_footprint_odom:="True"`、`launch_fake_vel_transform:="False"`、`launch_chassis_vel_transform` 随模式自动联动）。
- 导航编排：`ats_nav_bringup` 的 `bringup_launch.py`、`navigation_launch.py`、`rm_navigation_reality_launch.py`、`localization_launch.py`。
- MuJoCo 入口：`ats_mujoco_sim/launch/rmuc_2027_mujoco.launch.py`（默认有图 `slam:=false`、`solver_mode:=qp`）。
- Gazebo 历史入口：`rmu_gazebo_simulator/launch/rmuc_2027_gazebo.launch.py`（冻结未启用，旧地图接口待迁移）。
- 串口入口：`standard_robot_pp_ros2/launch/standard_robot_pp_ros2.launch.py`。
- 视觉入口：`sp_vision25` 的 ROS 2 条件编译可执行文件和 `io::GimbalTopicBridge`。

## 构建

```bash
./build.sh --packages-select ats_nav_bringup ats_sentry_bringup ats_mujoco_sim
```

## 启动与雷达安装契约

- `real_robot_navigation.launch.py` 默认 `lidar_mount_mode:="gimbal"` + `gimbal_use_base_footprint_odom:="True"`：启用 `base_footprint` 里程计解耦（`sensor_scan_generation` 仅发 `odom -> base_footprint`、关闭 `publish_robot_base_tf`、`ats_rog_map` `base_ground_offset:=0.0`、`loam_interface` `base_frame_height:=0.15`、`point_lio` 同步倾斜重力向量、`sentry_chassis_vel_transform` 启用且 `transform_linear_with_big_yaw:=False`）；显式传 `gimbal_use_base_footprint_odom:=False` 可回退至 `gimbal_yaw_odom` + 大 yaw 前馈延迟补偿。
- `bringup.launch.py` 默认 `lidar_mount_mode:="chassis"`，`launch_fake_vel_transform:="False"`、`launch_chassis_vel_transform:="False"`。
- `fake_vel_transform` 关闭时仍保留 `gimbal_yaw_odom -> gimbal_yaw_fake` 零旋转兼容 TF；以上组合均由 `scripts/validate_navigation_config.py` 静态锁定。

## 接口与架构

```text
static map + Point-LIO/fusion -> ROGMap/adapter (PlanningMapSnapshot) -> 混合搜索/MINCO -> Goal Manager
 -> 唯一 OSQP SQP-RTI MPC (/cmd_vel/autonomy_raw)
 -> [实机可选 sentry_chassis_vel_transform -> /cmd_vel/autonomy]
 -> cmd_vel_arbiter (/cmd_vel/selected) -> 串口 / MuJoCo (/motion_control)
```

`static_map_publisher.py` 提供 transient-local `/map`；Goal Manager 唯一消费 `/goal_pose` 并提供 `/ats_navigate_to_pose` action；串口节点发布 `/serial/link_up`、`/serial/gimbal_state`、`/serial/gimbal_cmd`，视觉不再创建第二个串口读写者。

## 验证与限制

全部启动组合已通过 `validate_navigation_config.py` 与 `ros2 launch ... --show-args` 静态核验；MuJoCo 2027 无窗口 Stage A（T1/T2/B1/V1/B2/F）已通过。实车双 yaw 云台标定与硬件联调、T3 `six_tunnels`、Stage B 开放门、开窗 GUI 与 P3 行为树全链集成仍待验证，详见 [2027 导航验证方案](../nav_acceptance/20261116_2027_final_test_plan.md)。
