# 启动入口与运行链路

## 简介

正式导航使用 ATS 自研地图、action、MINCO 和 MPC。所有生产入口均不启动 Nav2 server，不使用 `/plan`。

## 模块

- 根入口：`src/ats_sentry_bringup/launch/bringup.launch.py`。
- 中立实机入口：`src/ats_sentry_bringup/launch/real_robot_navigation.launch.py`。
- 导航编排：`ats_nav_bringup` 的 `bringup_launch.py`、`navigation_launch.py`、
  `rm_navigation_reality_launch.py`、`localization_launch.py`。
- MuJoCo 入口：`ats_mujoco_sim/launch/rmuc_2027_mujoco.launch.py`（兼容入口仍保留）。
- Gazebo 入口：`rmu_gazebo_simulator/launch/rmuc_2027_gazebo.launch.py`，底层导航由 `ats_gazebo_nav.launch.py` 编排。
- 串口入口：`standard_robot_pp_ros2/launch/standard_robot_pp_ros2.launch.py`。
- 视觉入口：`sp_vision25` 的 ROS 2 条件编译可执行文件和 `io::GimbalTopicBridge`。
- 轻量执行端：`nav2_loopback_sim/launch/loopback_simulation.launch.py`。

## 依赖

入口依赖根 `node_params.yaml`、地图/PCD 资产、定位与底盘桥包。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --symlink-install --parallel-workers 1
```

## 启动

```bash
ros2 launch ats_sentry_bringup bringup.launch.py \
  world:=rmuc_2026 planning_grid_owner:=rog_map use_rviz:=false
```

实机默认保留 fake-yaw 和 chassis transform 兼容层；固定雷达迁移仅以启动参数关闭并维持 topic、
TF 与速度 frame 契约。

## 接口

`static_map_publisher.py` 提供 transient-local `/map`。Goal Manager 是 `/goal_pose` 的唯一 consumer，
并提供 `/ats_navigate_to_pose` action。MPC 唯一发布 `/cmd_vel/autonomy_raw`；实机经既有速度坐标
变换至 `/cmd_vel/autonomy`，随后由 arbiter 与手动 `/cmd_vel` 选择唯一的 `/cmd_vel/selected` 到下位机。
串口节点发布 `/serial/link_up`，并通过 `/serial/gimbal_state`/`/serial/gimbal_cmd` 与视觉交互；
视觉不得再创建第二个串口读写者。

## 配置

入口只覆盖 `use_sim_time` 与资产/设备路径；ROGMap、adapter、MINCO、Goal Manager 和
MPC 参数由根总 YAML 提供。`planning_grid_owner` 固定为 `rog_map`，运行中建议避免热切换。

## 架构

```text
static map + Point-LIO -> ROGMap/adapter -> MINCO -> Goal Manager -> MPC
-> /cmd_vel/autonomy_raw -> cmd_vel_arbiter -> /cmd_vel/selected -> final bridge
```

## 验证与限制

已执行变更 launch 的 `py_compile`、`ros2 launch --show-args` 和静态速度契约检查；导航 yaw 相关 CTest 为 `3/3`。
串口 PTY 双向回环和视觉 ROS 2 构建分别通过。MuJoCo `tunnel_B` 已通过；Gazebo 2027 world/SDF、
模型依赖、RViz 入口和 headless `/registered_scan` 已检查；因此 Gazebo 重定位链可验收，action/终点、
P2 fault matrix 和物理接触仍未通过。
