更新日期：2026-11-24。模块完成状态、未优化根因与下一阶段提示词统一见 [主报告](../调研/无先验地图钻洞高速导航优化调研报告.md) 第 5/9 节，2027 验收口径与实测矩阵统一见 [2027 导航验证方案](../nav_acceptance/20261116_2027_final_test_plan.md)。本文仅保留框架级状态索引。

## 当前活动链

```text
Point-LIO (批量更新 + SO(3) 前向传播) + small_gicp (Schur SE(2) + LOST Scan Context) + fusion
 -> ats_rog_map (odom 全局层 + TUNNEL_FREE + 进程内 adapter) -> PlanningMapSnapshot
 -> 统一混合图搜索 + MINCO S3 (bicubic) + 独立 yaw + 自适应连续扫掠足迹门 + Local Collision Repair
 -> Goal Manager (带导数参考 + 提交屏障) -> 唯一 OSQP SQP-RTI SE(2) MPC -> arbiter -> /cmd_vel/selected
```

地图快照携带 occupancy、signed distance、梯度、`source_generation`、`publication_sequence` 和 `localization_epoch`。MINCO 单次规划绑定同一不可变本地快照；不同编号域不要求数值相等。
