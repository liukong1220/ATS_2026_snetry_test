# ATS 导航代码框架优化方向与验证状态

2026-11-16文档审查：模块完成状态与实施提示词统一见[主报告](../调研/无先验地图钻洞高速导航优化调研报告.md)第5节，最终用例统一见[2027测试方案](../nav_acceptance/20261116_2027_final_test_plan.md)。本文只保留框架入口和状态边界。

## 当前活动链

```text
Point-LIO + 独立定位/地图匹配
 -> ats_rog_map（进程内 adapter）-> PlanningMapSnapshot
 -> JPS / MINCO / 独立 yaw / footprint gate / Local Collision Repair
 -> Goal Manager 提交复核 -> SE2 MPC -> arbiter -> selected -> 底盘
```

地图快照携带 occupancy、signed distance、梯度、来源 generation、publication sequence 和 localization epoch。MINCO 单次规划固定同一不可变本地快照；不同编号域不要求数值相等。字段存在不能代替跨进程拒绝陈旧数据的运行证据。

## 参数和验收

三套profile长×宽0.581×0.571 m、margin 0.02 m、ROG/terrain车高门0.249 m、JPS配置0.36 m、隧道yaw和spin启用。MINCO参考/最大速度、MPC轴向/轮速及出口平移暂定上限5 m/s，yaw 3 rad/s、角加速度2 rad/s²；不把参数同步写成实车验收。

当前最终套件为RMUC 2027真实隧道和默认起点(13.40,2.00)到对称点(14.60,14.00)的ATS action导航速度，另跑独立P2故障矩阵。记录reference、MPC、selected、MotionCtrl和真值曲线；5 m/s未触发时单列未验证。旧红框/矩形是历史兼容，不再作为当前必过项。P3仍须证明无Nav2 graph/依赖入口且当前套件通过，不能从自研action已存在推导完成。
