# 导航定位与轨迹链路

## 简介

导航链以 Point-LIO、small_gicp 方向信息重定位融合、ROGMap（进程内 adapter）、RC-ESDF、统一混合图搜索、MINCO S3（`bicubic` 距离场 + 独立 yaw + 自适应连续扫掠足迹门）与唯一 `OSQP v1.0.0 SQP-RTI` 全向 SE(2) MPC 为权威。2027 隧道通过侧壁 PCA / ESDF 轴线预对齐让 `0.571 m` 面正对隧道。

## 模块

- **定位前端与融合**：`point_lio`（批量更新、IMU 饱和降级、`projectSO3()` 高频前向传播、`/odometry_identified` 身份链）、`small_gicp_relocalization`（Schur SE(2) 方向信息、`LOST`-only Scan Context）、`localization_fusion`（弱轴正交抑制 + NIS 门控融合，独占 `map->odom`）。
- **地图与快照**：`ats_rog_map`（`odom` 全局层、地面相对列、`TUNNEL_FREE`、进程内 `planning_map_publisher`）链接 `ats_rc_esdf` 增量距离场库，唯一发布 `/rog_map_adapter/planning_snapshot`。
- **规划与目标管理**：`ats_goal_manager` 与 `minco_planner`（统一 `hybrid` 搜索、非零尾状态/带导数参考、自适应连续扫掠矩形足迹门、Local Collision Repair）。
- **控制**：`ats_swerve_mpc`（唯一 `solver_mode: qp` OSQP SQP-RTI，50 Hz 实时控制解耦、执行器延迟增广、沿迹/横迹权重、旋转系速度搬运 $R(-\omega_z\Delta t)$ 与 rollout 预测安全门）。

## 构建

```bash
./build.sh --packages-select ats_navigation_interfaces ats_rc_esdf ats_rog_map \
  minco_planner ats_goal_manager ats_swerve_mpc point_lio small_gicp_relocalization
```

## 接口

- Point-LIO：`/aft_mapped_to_init_identified` -> `/odometry_identified`、`/localization`、`/registered_scan`。
- 重定位与状态：`/relocalization_observation`（含 SE(2) 方向信息与退化掩码）、`/localization/status`。
- 规划快照：`/rog_map_adapter/planning_snapshot`（`PlanningMapSnapshot`，含 occupancy、signed distance、梯度、`publication_sequence`、`source_generation`、`localization_epoch`）、`/rog_map_adapter/ready`、`/rog_map_adapter/status`；不从 `/rog_map/esdf` 点云反解析数值 ESDF。
- 目标与执行授权：`/ats_navigate_to_pose`、`/planner/emergency_stop`、`/planner/execution_command`（含带导数参考）。

## 架构

```text
Point-LIO + small_gicp/fusion -> ROGMap/adapter -> immutable MINCO snapshot
 -> hybrid search / MINCO (bicubic) / yaw / adaptive swept footprint
 -> Goal Manager recheck/retime -> 唯一 OSQP SQP-RTI MPC -> body-frame [vx, vy, wz]
```

## 验证与限制

2026-11-23 无窗口 2027 实测已通过 Stage A T1/T2/B1/V1/B2 及 5 项故障与 Stage B 3 点建图保存/B2/故障；OSQP `qp_backend p95=0.887–1.826 ms`、`0` 告警，Point-LIO 离线 `APE RMSE=0.020–0.078 m`、`LIO p95=6.32–7.05 ms`。剩余关键待优化项为 O5b 南侧退化区方向门控重标定（T3）、O2 长距离局部滚动裁剪与拼接（B1 MINCO `p95=184.43 ms`）、Stage B 6 项 S3 门、独立物理接触与实车联调，见 [2027 导航验证方案](../nav_acceptance/20261116_2027_final_test_plan.md)。
