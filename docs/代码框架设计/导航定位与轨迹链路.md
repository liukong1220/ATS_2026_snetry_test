# 导航定位与轨迹链路

## 简介

导航链以 Point-LIO 或 Gazebo 真值定位、ROGMap 语义、RC-ESDF、JPS/MINCO 和全向 SE2 MPC 为权威；Gazebo 真值模式只替换输入 producer，不改变下游接口。2027 隧道额外要求 yaw 对齐 ESDF 估计轴线，并让 `0.571 m` 面正对隧道。

## 模块

Point-LIO、`ats_rog_map`（含进程内 adapter，即 `planning_map_publisher`）、`minco_planner`、
`ats_goal_manager` 和 `ats_swerve_mpc` 分别拥有定位、地图与规划快照、轨迹与控制职责；`ats_rc_esdf` 是
`ats_rog_map` 链接的距离场与静态图融合库，不是独立节点。原 `ats_rog_map_adapter` 包随 M3/M4 并入 `ats_rog_map`。

## 依赖

依赖 ROS 2 Humble、PCL/Eigen 及活动导航接口包；不依赖 Nav2。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --symlink-install --parallel-workers 1 \
  --packages-select ats_rc_esdf ats_rog_map minco_planner --cmake-args -DCMAKE_BUILD_TYPE=Release
```

## 启动

经根 bringup 启动。规划地图唯一所有者是 `ats_rog_map` 进程内的 adapter，没有 owner 二选一参数。

## 接口

- Point-LIO：`/localization`、`/registered_scan`。
- Gazebo GT 模式：`gazebo_gt_odometry_relay` 发布 `/odometry`，`gazebo_gt_registered_scan_relay` 发布 `/registered_scan`；两者与 Point-LIO 模式互斥。
- 规划快照：`/rog_map_adapter/planning_snapshot`（`PlanningMapSnapshot`，含 `publication_sequence`、`source_generation`、`localization_epoch`），以及 `/rog_map_adapter/ready`、`/rog_map_adapter/status`；投影在进程内完成，没有 projection service。
- 规划栅格可视化：`/rog_map_adapter/viz/planning_grid`，只供 RViz。
- navigation action：`/ats_navigate_to_pose`。
- 执行安全：`/planner/emergency_stop`、`/planner/execution_command`。

建议避免从 `/rog_map/esdf` PointCloud2 反解析数值 ESDF。

Gazebo 的完整 topic/frame/QoS/所有权账本见 [Gazebo 与当前导航接口](Gazebo与当前导航接口.md)。

## 配置

总 YAML 明确记录 topic、frame、QoS、timeout 与默认值。ROGMap core 从显式参数 struct 构造；正式
profile 不混用私有地图 YAML。静态图融合保留 signed distance、unknown、gradient、outside-map、
origin/yaw 与保守 occupied 语义。

## 架构

```text
state estimate -> ROGMap/adapter -> immutable MINCO snapshot -> JPS/MINCO/yaw/footprint
               -> Goal Manager recheck/retime -> SE2 MPC -> body-frame velocity
```

JPS、MINCO clearance、footprint gate 与 repair 在一次规划内共享 MINCO immutable snapshot。

## 验证与限制

已通过语义、snapshot、MINCO、Goal Manager action 单测，以及隧道 yaw、yaw spline、terminal relocation 三项 CTest（`3/3`）。MuJoCo `tunnel_B` 进入/通过，隧道内最大 yaw 误差约 `4.9e-12`、终点误差 `0.0`。Gazebo 2027 headless 重定位已通过；P4 连续 swept footprint、实车动力学约束、物理接触 evaluator 和实车运行仍未验证。
