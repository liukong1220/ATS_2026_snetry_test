# 接口消息与话题约定

## 简介

接口契约覆盖 frame、time、map/ESDF 语义、QoS、generation、owner 与故障确定性零速度。

## 依赖与构建

ROS 2 接口由 `ats_navigation_interfaces`、`ats_rog_map_interfaces` 与标准消息包定义。接口变更后使用 `./build.sh` 做 Release 构建并执行 `python3 scripts/validate_navigation_config.py`。

## 核心话题与所有权

| 名称 | 契约 |
| --- | --- |
| `/ats_navigate_to_pose` | ATS 自研 action：目标、feedback、result、cancel、preempt、timeout |
| `/odometry_identified` | Point-LIO 身份化里程计（`odom_instance_id`、`odom_epoch`），独占前端身份链 |
| `/relocalization_observation` | `small_gicp_relocalization` 发布，含 SE(2) 方向信息矩阵、弱轴方向与退化掩码 |
| `/localization/status` | `localization_fusion` 独占发布，含状态、`epoch` 与 `map_to_odom` 有效性 |
| `/rog_map_adapter/planning_snapshot` | `ats_rog_map` 进程内 adapter 唯一发布：occupancy、signed distance、梯度、`source_generation`、`publication_sequence`、`localization_epoch` |
| `/rog_map_adapter/ready` / `status` | adapter 心跳；租约超时确定性触发地图失效与急停 |
| `/planner/execution_command` | Goal Manager 独占执行授权（含带导数参考、滚动标志与提交屏障） |
| `/planner/emergency_stop` | stale/unknown/unreachable/unsafe/MPC 失败确定性安全停止 |
| `/cmd_vel/autonomy_raw` | `ats_swerve_mpc`（唯一 OSQP SQP-RTI）车体系 `[vx, vy, wz]` 唯一自主源 |
| `/cmd_vel` | 手动输入，保持 ROS 默认，不依赖 `ExecutionCommand` |
| `/cmd_vel/autonomy` | 实机 `sentry_chassis_vel_transform` 输出的自主源 |
| `/cmd_vel/selected` | `cmd_vel_arbiter` 唯一输出；串口与仿真最终执行端唯一允许的 Twist 输入 |
| `/serial/link_up` | `std_msgs/msg/Bool`，串口 50 ms 心跳，断连为 `false` |
| `/serial/gimbal_state` / `gimbal_cmd` | 视觉与唯一串口宿主 `standard_robot_pp_ros2` 之间的云台状态/命令桥接 |
| `serial/gimbal_joint_state` | 云台大 yaw 编码器状态，供速度坐标变换与自瞄-导航协调使用 |

## 架构与冗余治理说明

- `ROGMap source_generation`、`adapter publication_sequence`、`localization_epoch` 与 `MINCO local snapshot generation` 属于不同编号域，不要求数值相等；单次 MINCO 规划内共享不可变快照。
- 下一阶段导航域精简计划（不触碰视觉与串口）将收敛未订阅/重复的诊断话题（如 `terrain_analysis_ext` 未被消费的 5 个辅助栅格/点云、`ats_rog_map` 重复可视化通道与 `minco_planner` 多条中间调试路径），详见 [主报告第 5.2 节](../调研/无先验地图钻洞高速导航优化调研报告.md#52-未优化项根因与精确技术方案)。
- DDS 跨 topic 不提供原子顺序，安全提交继续依赖 Goal Manager 统一提交点（含 `stop_to_reference_guard_sec`）、MPC 旧参考拒绝门与 arbiter 独立租约。
