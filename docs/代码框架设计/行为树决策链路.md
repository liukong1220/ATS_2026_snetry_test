# 行为树决策链路

## 简介

行为树只通过 ATS navigation action（`/ats_navigate_to_pose`）请求运动，不拥有规划地图、速度或底盘输入。

## 模块与构建

`ats_sentry_behavior` 的行为树、server/client 与任务条件节点组成决策层；`ats_goal_manager` 拥有目标生命周期与急停。

```bash
./build.sh --packages-select ats_sentry_behavior
```

## 接口与架构

```text
mission / vision / referee -> ats_sentry_behavior -> /ats_navigate_to_pose
 -> ats_goal_manager -> minco_planner -> ats_swerve_mpc -> cmd_vel_arbiter
```

- 多航点按序调用 `/ats_navigate_to_pose`，支持 feedback、result、cancel、preempt 与 timeout；`/goal_pose` 的唯一消费方为 `ats_goal_manager`。
- 行为参数只选择任务树与业务条件，导航算法参数统一位于 `src/ats_sentry_bringup/params/node_params.yaml`。

## 验证与限制

当前 Waves 0–5 导航底座已在 RMUC 2027 无窗口 Stage A 通过 T1/T2/B1/V1/B2 与 5 项独立故障（详见 [2027 导航验证方案](../nav_acceptance/20261116_2027_final_test_plan.md)）；**但 `ats_sentry_behavior` 在新导航栈上的多航点/抢占/取消/超时端到端集成验收、P3 最终门禁、比赛裁判联动与实车视觉联动均尚未复验**（已纳入主报告 Wave 6C 计划）。
