# 行为树决策链路

## 简介

行为树只通过 ATS navigation action 请求运动，不拥有规划地图、速度或底盘输入。

## 模块

`ats_sentry_behavior` 的官方树、server/client 和任务条件节点组成决策层；Goal Manager 拥有
目标生命周期与急停。

## 依赖

BehaviorTree.CPP/ROS 2、`ats_navigation_interfaces` 和根行为参数。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --packages-select ats_sentry_behavior --parallel-workers 1
```

## 启动

根 bringup 可启动行为层；受控 HIL 可关闭 `launch_behavior` 以隔离导航安全测试。

## 接口

多航点按序调用 `/ats_navigate_to_pose`，从 action 接收 feedback/result，支持 cancel、preempt 和
timeout。`/goal_pose` 的唯一 consumer 是 Goal Manager。

## 配置

行为参数只选择任务树、目标与条件；导航算法参数在根 `node_params.yaml`，建议避免形成第二 owner。

## 架构

```text
mission/vision/referee -> behavior tree -> ATS action -> Goal Manager -> planner/controller
```

## 验证与限制

本轮行为逻辑和 ATS action 测试通过，并在 MuJoCo 覆盖 cancel/preempt/timeout。比赛任务与实车
视觉联动未在本轮运行。
