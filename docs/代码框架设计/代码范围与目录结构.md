# 代码范围与目录结构

## 简介

活动源码只在 `src`；根仓、导航仓和 MuJoCo 仓为独立 Git 仓库。

## 模块

- 根仓：`src/ats_sentry_bringup`、根脚本（`scripts/`）、地图/PCD 资产、`AGENTS.md` 与 `docs/`。
- 导航仓：`src/ats_sentry_nav` 的 Point-LIO、small_gicp/fusion、ROGMap、RC-ESDF、MINCO、Goal Manager、唯一 OSQP SQP-RTI MPC、速度仲裁与导航 launch。
- MuJoCo 仓：`src/sim/ats_mujoco_sim` 的四舵轮物理、CPU/GPU LiDAR、2027 隧道场景、bridge 与 RViz 配置。
- Gazebo 仓：`src/sim/gazebo_simulator`（暂冻结未启用，旧地图接口待迁移）。
- 串口仓：`src/standard_robot_pp_ros2`，是底盘、云台和链路的唯一串口读写者。
- 视觉仓：`src/sp_vision25`，ROS 2 条件编译时通过 `GimbalTopicBridge` 使用串口话题，不直接打开云台串口。

## 依赖与构建

依赖通过 ROS package manifest 和 `dependencies.repos` 解析；`参考/` 仅作算法/许可证溯源，不是活动构建输入。构建统一使用根目录 `./build.sh`（内部使用 `--base-paths src -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF`）。

## 启动与接口

- 入口由 `bringup.launch.py`、`real_robot_navigation.launch.py`、`ats_nav_bringup`、`rmuc_2027_mujoco.launch.py`、串口 launch 与视觉 ROS 2 可执行文件组成。
- 跨域接口以 `ats_navigation_interfaces` / `ats_rog_map_interfaces` 的 `.msg/.srv/.action` 为准，参数单一权威为 `src/ats_sentry_bringup/params/node_params.yaml`。

## 架构

```text
视觉 ROS 2 topics <-> standard_robot_pp_ros2 (唯一串口 owner)
       |                                      |
       +-> behavior -> Goal Manager -> ROGMap/adapter -> 混合搜索/MINCO/yaw -> OSQP SE(2) MPC
                                                         -> cmd_vel_arbiter -> /cmd_vel/selected
                                                         -> MuJoCo (/motion_control) / 串口底盘
```

三套 profile 车体统一为 `0.581 × 0.571 m`、余量 `0.02 m`、车高门 `0.249 m`、终端容差 `0.05 m`；隧道通过时宽 `0.571 m` 面正对隧道，yaw 对齐侧壁/ESDF 估计轴线。
