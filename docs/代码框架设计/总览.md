# 项目总览

## 简介

ATS 哨兵当前正式 ROS 2 导航为自研 ROGMap、RC-ESDF、MINCO、Goal Manager 和全向 MPC 链。

## 模块

根仓拥有 bringup/配置，导航仓拥有算法，MuJoCo 与 Gazebo 仓提供两种仿真域；
`standard_robot_pp_ros2` 是串口唯一 owner，`sp_vision25` 在 ROS 2 模式通过话题桥接云台；行为仓通过 ATS action 下发目标。

## 依赖

ROS 2 Humble 与各包 `package.xml` 依赖；`参考/` 不进入活动构建。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --symlink-install --parallel-workers 1
```

## 启动

`bringup.launch.py` 和 `real_robot_navigation.launch.py` 固定自研导航；2027 回归使用
`rmuc_2027_mujoco.launch.py` 或 `rmuc_2027_gazebo.launch.py`，旧 `rmuc_2025/2026` 入口仅作兼容。

## 接口

ATS action 是 `/ats_navigate_to_pose`；当前目标速度链是
`/cmd_vel/autonomy_raw ->（实机可选 fake/chassis 变换）-> cmd_vel_arbiter -> /cmd_vel/selected`。
`/cmd_vel` 保留为手动输入，不再作为自主最终输出。串口桥额外提供 `/serial/link_up`、
`/serial/gimbal_state`（11 元，四元数 `wxyz`）和 `/serial/gimbal_cmd`（7 元，角度 rad）；
视觉 ROS 2 入口只使用这三个接口。

## 配置

根 `node_params.yaml` 是正式节点参数总 YAML；launch 不提供第二份算法参数源。

## 架构

```text
Point-LIO -> ROGMap/adapter -> RC-ESDF -> JPS/MINCO -> Goal Manager -> SE2 MPC -> chassis
```

## 验证与限制

已验证串口 PTY 回环、视觉 ROS 2 CTest、MuJoCo `tunnel_B` 和导航 yaw CTest；Gazebo 2027 入口、
world/SDF、模型依赖、同风格 RViz 和 headless direct LiDAR bridge 已验证；`/registered_scan` 与 GICP accepted/CONFIRMED 已实测。完整 Gazebo 红框导航仍需单独验收。
物理接触 evaluator、实车/HIL、P3 Nav2-free、P4 连续 swept 仍未完成。仿真不以 CAN、电机、轮速、
接触或底盘反馈作为唯一通过条件。活动执行入口为：
