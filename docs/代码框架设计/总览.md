# 项目总览

## 简介

ATS 哨兵当前正式 ROS 2 导航为自研 Point-LIO、small_gicp 方向融合、ROGMap、RC-ESDF、MINCO、Goal Manager 与唯一 `OSQP v1.0.0 SQP-RTI` 全向 SE(2) MPC 链，零 Nav2 依赖。

## 模块

根仓拥有 bringup/总参数/脚本/文档，导航仓拥有定位/建图/规划/控制算法，MuJoCo 仓提供 2027 物理仿真域（Gazebo 暂冻结未启用）；`standard_robot_pp_ros2` 是串口唯一 owner，`sp_vision25` 在 ROS 2 模式通过话题桥接云台；`ats_sentry_behavior` 通过 ATS action 下发目标。

## 依赖

ROS 2 Humble 与各包 `package.xml` 依赖；`参考/` 不进入活动构建。

## 构建

整仓使用根目录 `./build.sh`（自动按可用内存与 CPU 核数计算并发，`-DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF`）；窄构建使用 `./build.sh --packages-select <targets>`。

## 启动

`bringup.launch.py`（默认 `lidar_mount_mode:=chassis`）与 `real_robot_navigation.launch.py`（默认 `lidar_mount_mode:=gimbal` + `gimbal_use_base_footprint_odom:=True`）使用自研导航；仿真回归使用 `rmuc_2027_mujoco.launch.py`（默认有图 `slam:=false`）与 `scripts/s3_mujoco_acceptance.py`。Gazebo 暂未启用且旧地图接口待迁移。

## 接口

ATS action 是 `/ats_navigate_to_pose`；速度链是 `/cmd_vel/autonomy_raw ->（实机可选 sentry_chassis_vel_transform）-> cmd_vel_arbiter -> /cmd_vel/selected`。`/cmd_vel` 保留为手动输入。串口桥额外提供 `/serial/link_up`、`/serial/gimbal_state`（11 元，四元数 `wxyz`）和 `/serial/gimbal_cmd`（7 元，角度 rad）；视觉 ROS 2 入口只使用这三个接口。

## 配置

根 [node_params.yaml](../../src/ats_sentry_bringup/params/node_params.yaml) 是正式节点参数总 YAML，由 [validate_navigation_config.py](../../scripts/validate_navigation_config.py) 锁定单一权威与唯一 `solver_mode: qp`。

## 架构

```text
Point-LIO + small_gicp/fusion -> ROGMap/adapter (PlanningMapSnapshot)
 -> 混合 JPS/A* + MINCO (bicubic) + 自适应连续扫掠 -> Goal Manager
 -> 唯一 OSQP SQP-RTI SE(2) MPC -> arbiter -> chassis / MuJoCo
```

## 验证与限制

截至 2026-11-23 Waves 0–5 完成：有图无窗口 2027 仿真已通过 T1 `tunnel_b_roundtrip`（13/13）、T2 `ramp_south`（13/13）、B1 基地到基地（28.26 m）、V1 对称点速度（16.41 m，峰值 `2.223 m/s`）、B2 动态绕行及 5/5 独立故障，OSQP `0` 告警、`qp_backend p95=0.887–1.826 ms`。**未通过/未验证项**：T3 `six_tunnels`（`16/42` 南侧 GICP 漂移）、B1 长段 MINCO `< 20 ms` 墙钟预算、Stage B 无先验 6 项 S3 开放门、`5 m/s` 高速段、独立物理接触评估、开窗 RViz/MuJoCo 画面、P3 行为树全链集成及实车硬件联调。
