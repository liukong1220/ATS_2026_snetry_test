# 接口消息与话题约定

本文档根据 `src/interfaces`、`src/ats_sentry_nav/*/msg` 和相关源码中的发布订阅整理。

## 接口域划分

```text
src/interfaces/
├── ats_rm_interfaces/       # 实车裁判系统、云台、机器人状态
├── sp_msgs/                 # 视觉、行为树、导航之间的融合消息
├── carstatemsgs/            # 仿真车体状态与轨迹
└── manda_can_control/       # MuJoCo / 舵轮 CAN 控制与反馈
```

## `ats_rm_interfaces`

用途：

- 串口桥发布裁判系统和机器人状态。
- 行为树订阅裁判系统状态。
- 云台命令由行为树或视觉侧生成后给 `gimbal_manager` 消费。

主要消息：

- `Gimbal.msg`：pitch / yaw 及速度控制范围。
- `GimbalCmd.msg`：云台控制命令，支持绝对角和速度控制。
- `Models.msg`：底盘、云台、发射、机械臂、自定义控制器模型描述。
- `RobotStateInfo.msg`：机器人模型状态。
- `referee/GameStatus.msg`：比赛阶段和剩余时间。
- `referee/RobotStatus.msg`：机器人 ID、等级、血量、热量、弹量、伤害原因。
- `referee/RfidStatus.msg`：RFID 增益点状态。
- `referee/EventData.msg`：场地事件状态。
- `referee/GameRobotHP.msg`：全场机器人、前哨站、基地血量。
- `referee/GroundRobotPosition.msg`：己方地面机器人位置。
- `referee/Buff.msg`：回血、冷却、防御、攻击和剩余能量。

关键话题：

- `referee/game_status`
- `referee/robot_status`
- `referee/rfid_status`
- `referee/event_data`
- `referee/all_robot_hp`
- `referee/ground_robot_position`
- `referee/buff`
- `cmd_gimbal`
- `serial/robot_state_info`

## `sp_msgs`

用途：

- 视觉向行为树发布目标状态。
- 导航轨迹优化向速度治理发布 trajectory profile。
- 行为/导航向视觉发布敌方状态或指定目标。

主要消息：

### `VisionTargetMsg`

发布方：

- `sp_vision25/io/ros2/publish2nav.cpp`
- `ats_sentry_bringup/scripts/fake_decision_sim_inputs.py`

订阅方：

- `ats_sentry_behavior_server`

关键字段：

- `timestamp`：视觉结果时间戳。
- `tracking`：是否稳定追踪目标。
- `nav_hold`：是否建议导航进入视觉接管。
- `fire_permitted`：是否允许开火。
- `target_id` / `target_type`：目标编号和类型。
- `confidence`：置信度。
- `target_distance`：目标距离。
- `target_yaw` / `target_pitch`：云台目标角。
- `target_position_gimbal`：云台坐标系目标点。
- `target_position_map`：地图坐标系目标点。
- `has_target_position_map`：地图点是否有效。
- `target_position_map_frame`：地图点所属 frame。

### `TrajectoryProfileMsg`

发布方：

- `trajectory_optimizer_node`
- `Nav2BSplineSmoother`

订阅方：

- `trajectory_speed_governor`

关键字段：

- `total_length`
- `total_time`
- `curvature_penalty`
- `velocity_smoothness_cost`
- `obstacle_cost`
- `total_cost`
- `max_abs_curvature`
- `points[]`

`TrajectoryProfilePoint` 包含路径弧长、时间、点、导数、曲率、速度限制、速度和加速度。

### `EnemyStatusMsg` / `AutoaimTargetMsg`

用途：

- `sp_vision25/io/ros2/subscribe2nav.cpp` 订阅 `enemy_status` 和 `autoaim_target`。
- 视觉侧用这些消息过滤无敌目标或接收优先目标。

## `carstatemsgs`

用途：

- MuJoCo 仿真和 DDR-opt 风格轨迹/状态接口。

主要消息：

- `CarState`：x、y、yaw、弧长、速度、角速度、加速度、jerk。
- `SimulatedCarState`：仿真车体速度、ICR、角速度。
- `TrajectoryPoint`：位姿、体坐标速度、角速度、加速度。
- `TrajectorySegment`：轨迹片段。
- `Polynome`：多项式轨迹边界条件。
- `KinematicState`：动力学约束状态。
- `CarControl`：左右轮角速度控制。

MuJoCo 中 `ats_mujoco_sim` 使用 `CarState` 发布或接收仿真位姿相关数据。

## `manda_can_control`

用途：

- MuJoCo 舵轮仿真控制与反馈。
- `ats_mujoco_sim` 订阅控制消息并发布反馈消息。
- `twist_to_motion_ctrl` 将 Nav2 `Twist` 转成 `MotionCtrl`。

消息：

- `MotionCtrl`：`linear_x`、`linear_y`、`angular_z`。
- `MotionFb`：运动反馈。
- `SpeedCtrl` / `SpeedFb`：四轮速度控制与反馈。
- `SteerCtrl` / `SteerFb`：四轮转向角控制与反馈。
- `BatteryFb`
- `FaultFb`
- `SystemstateFb`

服务：

- `MotionMode.srv`
- `ControlMode.srv`
- `DoCtrl.srv`

## 导航自定义消息

`livox_ros_driver2/msg`：

- `CustomMsg`
- `CustomPoint`

用于 Livox 点云格式。

`point_lio/msg`：

- `LocalSensorExternalTrigger`

用于本地传感器触发时间。

## 主要话题关系

裁判系统：

```text
standard_robot_pp_ros2
  -> referee/*
  -> ats_sentry_behavior_server
```

视觉：

```text
sp_vision25
  -> vision/target
  -> ats_sentry_behavior_server
```

行为到导航：

```text
ats_sentry_behavior
  -> /navigate_through_poses
  -> /navigate_to_pose
```

行为到云台/底盘：

```text
ats_sentry_behavior
  -> cmd_gimbal
  -> gimbal_manager
  -> cmd_gimbal_joint

ats_sentry_behavior
  -> decision/robot_mode
  -> standard_robot_pp_ros2

ats_sentry_behavior
  -> cmd_spin
  -> fake_vel_transform
```

导航到下位机：

```text
Nav2
  -> cmd_vel_controller
  -> trajectory_speed_governor
  -> cmd_vel_controller_governed
  -> velocity_smoother
  -> cmd_vel_nav2_result
  -> fake_vel_transform
  -> cmd_vel_gimbal_yaw_odom
  -> sentry_chassis_vel_transform
  -> /cmd_vel
  -> standard_robot_pp_ros2
```
