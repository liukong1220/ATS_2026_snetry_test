# 接口消息与话题约定

## 简介

接口契约覆盖 frame、time、map/ESDF 语义、QoS、generation、owner 与故障零速度。

## 模块

定位、ROGMap、adapter、MINCO、Goal Manager、MPC 与 bridge 各自拥有输出边界。

## 依赖

ROS 2 接口由 `ats_navigation_interfaces`、`ats_rog_map_interfaces` 与标准消息包定义。

## 构建

接口变更后必须以 `colcon build --base-paths src` 重新生成并测试 consumer。

## 启动

启动时核查 `/rc_esdf/planning_grid`、`/planner/emergency_stop` 与 `/cmd_vel_mpc` 的
唯一 producer；下位机/HIL topic 不属于导航启动门禁。

## 接口

| 名称 | 契约 |
| :--- | :--- |
| `/ats_navigate_to_pose` | 目标、feedback、result、cancel、preempt、timeout |
| `/rog_map/get_ground_projection` | 数值 grid、signed distance、gradient 与 source generation |
| `/rc_esdf/planning_grid` | adapter 的唯一 OccupancyGrid 发布 |
| `/planner/execution_command` | Goal Manager 的执行授权与 sequence |
| `/planner/emergency_stop` | stale/unknown/unreachable/unsafe/MPC failure 的安全停止 |
| `/cmd_vel_mpc` | body-frame `[vx, vy, wz]` |
| `/cmd_vel` | 经云台 yaw 速度变换后的下位机速度接口 |
| `serial/gimbal_joint_state` | 云台 yaw、速度变换与自瞄-导航协调输入 |

## 配置

地图保留 resolution、origin/yaw、occupied/unknown/outside-map；ESDF 保留 signed-distance、
gradient 和 unknown 语义。不可用、陈旧或无路径时必须输出确定性零速度。

## 架构

ROGMap source、adapter publication 与 MINCO snapshot generation 不同；只保证一次 MINCO
规划内部共用不可变 snapshot。

## 验证与限制

本轮独立 MuJoCo 图检查验证导航权威 topic 的唯一 owner，fault 验证 `/cmd_vel_mpc=0`。DDS 跨 topic
不提供原子顺序，执行契约仍依赖 Goal Manager 的统一提交点。
