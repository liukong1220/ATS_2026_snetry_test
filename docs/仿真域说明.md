# 仿真域说明

## 简介

MuJoCo 是自研导航闭环的物理仿真证据来源；loopback 仅用于轻量栅格和行为回归。

## 模块

- `ats_mujoco_sim`：四舵轮动力学、接触、传感器、静态地图、ATS action 与速度 bridge。
- `loopback_sim`：简化运动学与 ray/grid 测试，不替代物理接触或闭环安全验收。

## 依赖

ROS 2 Humble、MuJoCo、活动导航包和根 `node_params.yaml`。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --packages-select ats_mujoco_sim \
  --symlink-install --parallel-workers 1
```

## 启动

每例使用新的 domain、无 viewer 和新的 MuJoCo 进程：

```bash
ROS_DOMAIN_ID=231 PLANNING_GRID_OWNER=rog_map \
  scripts/test_mujoco_minco_mpc_chain.sh
```

## 接口

MuJoCo 发布定位/点云与 telemetry，`ats_swerve_mpc` 唯一发布 `/cmd_vel_mpc`，
`twist_to_motion_ctrl` 唯一发布 `/motion_control`，MuJoCo 唯一消费后者。

## 配置

`rmuc_2026_mujoco.launch.py` 启动静态地图、ROGMap、adapter、MINCO、Goal Manager、MPC 和 bridge。
地图由 static map publisher 提供，不启动地图 lifecycle 管理器。默认 RViz 为 ROGMap/MINCO/MPC
诊断视图，未知层默认可关闭，ESDF 仅调试显示。

## 架构

```text
simulated sensor -> localization/scan -> ROGMap adapter -> MINCO -> Goal Manager
                 -> MPC -> /cmd_vel_mpc -> bridge -> /motion_control -> vehicle
```

## 验证与限制

已验证 rectangle、red_box 和九项 P2/P3 fault。rectangle/red_box 终点误差分别为
`0.004126 m`/`0.003696 m`；red_box raw/reference 点数为 `37/708`，离散 footprint 冲突为 `0`，
接触计数为 `0`。fault 包含 adapter lease、service timeout、input stale、unknown、unreachable、
cancel、preempt、timeout、TF failure，均观察到两级零速度。

现有 contact evaluator 不是连续 swept collision evaluator，不能据此声称实车无物理接触。
