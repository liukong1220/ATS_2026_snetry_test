# 项目总览

## 简介

ATS 哨兵当前正式 ROS 2 导航为自研 ROGMap、RC-ESDF、MINCO、Goal Manager 和全向 MPC 链。

## 模块

根仓拥有 bringup/配置，导航仓拥有算法，MuJoCo 仓拥有物理仿真，行为仓通过 ATS action 下发目标。

## 依赖

ROS 2 Humble 与各包 `package.xml` 依赖；`参考/` 不进入活动构建。

## 构建

```bash
MAKEFLAGS=-j1 colcon build --base-paths src --symlink-install --parallel-workers 1
```

## 启动

`bringup.launch.py` 和 `real_robot_navigation.launch.py` 固定自研导航，MuJoCo 使用
`rmuc_2026_mujoco.launch.py`。

## 接口

ATS action 是 `/ats_navigate_to_pose`；速度链是 `/cmd_vel_mpc -> /motion_control`。

## 配置

根 `node_params.yaml` 是正式节点参数总 YAML；launch 不提供第二份算法参数源。

## 架构

```text
Point-LIO -> ROGMap/adapter -> RC-ESDF -> JPS/MINCO -> Goal Manager -> SE2 MPC -> chassis
```

## 验证与限制

本轮 colcon、单测、launch 参数展示和独立 MuJoCo rectangle/red_box/fault 已执行。实车和 P4
连续 swept footprint 未验证。
