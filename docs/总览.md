# 哨兵项目维护总览

这份文档面向当前维护者，目标是用最少的跳转成本回答四个问题：

1. 当前真实主线是什么。
2. 每条主线的入口、参数和代码落点在哪里。
3. 出现某类问题时应该先看哪个包、哪个文件。
4. `docs/` 下每篇文档现在分别负责什么。

所有内容均以当前工作区代码、launch、参数文件和 README 为准。

## 1. 当前系统分层

当前工作区可以按 5 层理解：

| 层 | 目录 | 当前职责 |
| --- | --- | --- |
| 启动编排层 | `src/ats_sentry_bringup` | 实机 / loopback 总入口、参数整合、地图/PCD/RViz |
| 决策层 | `src/ats_sentry_behavior` | 行为树、视觉接管、姿态切换、路径生成、资源门控 |
| 导航与定位层 | `src/ats_sentry_nav` | Nav2、MPPI、B 样条、Traversability ESDF、恢复行为、重定位、点云链 |
| 轻量闭环仿真层 | `src/loopback_sim` | `/cmd_vel -> /odom/TF/scan/clock` 软件闭环 |
| 设备与接口层 | `src/standard_robot_pp_ros2` | 串口桥、裁判系统、底盘命令与模式下发 |

## 2. 当前真实主线

### 2.1 实机主线

```text
ats_sentry_bringup/bringup.launch.py
  -> standard_robot_pp_ros2
  -> ats_nav_bringup
  -> ats_sentry_behavior
  -> /navigate_through_poses
  -> SmacPlannerHybrid
  -> Nav2BSplineSmoother
  -> MPPI
  -> trajectory_speed_governor
  -> velocity_smoother
  -> fake_vel_transform
  -> /cmd_vel
  -> 下位机
```

当前导航过渡链已经从“纯 fake costmap ESDF”推进到语义化 traversability ESDF：

```text
terrain_analysis_ext
  -> terrain_map_ext
  -> traversability_grid
  -> traversability_height_diff_grid
  -> traversability_occupancy_ratio_grid
  -> traversability_ground_confidence_grid
  -> TraversabilityEsdfProvider
  -> Nav2BSplineSmoother / trajectory_optimizer_node
```

### 2.2 loopback 主线

```text
loopback_decision_sim.launch.py / loopback_vision_test.launch.py
  -> fake_decision_sim_inputs.py
  -> ats_sentry_behavior
  -> /navigate_through_poses
  -> SmacPlannerHybrid
  -> Nav2BSplineSmoother
  -> MPPI
  -> trajectory_speed_governor
  -> velocity_smoother
  -> fake_vel_transform
  -> /cmd_vel
  -> nav2_loopback_sim
  -> /odom + TF + /scan + /clock
```

### 2.3 恢复行为主线

```text
FollowPath 失败
  -> behavior_server
  -> BackUpFreeSpace
  -> 主走廊恢复搜索
  -> 必要时 centroid fallback
  -> 平均走廊 cost 高时自动降速
  -> RViz marker 区分 corridor / centroid_fallback
```

## 6. 问题定位优先级

### 6.1 视觉接管不生效

先看：

1. `vision/target`
2. `IsVisionTargetValid`
3. `IsRobotResourceMode(state="engage")`
4. `decision/robot_mode`
5. `decision/vision_follow_markers`

### 6.2 规划正常但速度过慢

先看：

1. `/trajectory_profile`
2. `/cmd_vel_controller`
3. `/cmd_vel_controller_governed`
4. `/cmd_vel_nav2_result`
5. `/cmd_vel`

### 6.3 恢复动作看起来“卡顿/碎步”

先看：

1. `behavior_server` 的 `BackUpFreeSpace` 参数
2. `back_up_free_space_markers`
3. `high_cost_speed_threshold`
4. `speed_filter_tau`
5. `translational_acc_limit / translational_decel_limit`

### 6.4 重定位不触发或触发太频繁

先看：

1. `small_gicp_relocalization` 参数
2. `registration_interval_s`
3. `max_accumulation_age_s`
4. `min_registration_translation_delta`
5. `min_registration_yaw_delta`
