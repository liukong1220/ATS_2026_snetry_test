# 导航定位与轨迹链路

本文档根据 `src/ats_sentry_nav`、`src/ats_sentry_bringup/params/node_params.yaml` 和仿真参数整理。

## 导航域代码范围

`src/ats_sentry_nav` 是导航域总目录，包含以下能力：

- 雷达驱动：`livox_ros_driver2`
- LIO 定位：`point_lio`
- PCD 重定位：`small_gicp_relocalization`
- 点云/里程计适配：`loam_interface`
- 地形点云：`terrain_analysis`
- 地形语义栅格：`terrain_analysis_ext`
- Nav2 bringup：`ats_nav_bringup`
- Nav2 插件：`ats_nav2_plugins`
- 轨迹平滑和速度治理：`trajectory_optimizer`
- 坐标/速度转换：`fake_vel_transform`、`sentry_chassis_vel_transform`
- 辅助工具：`sensor_scan_generation`、`pointcloud_to_laserscan`、`minco_planner`、`ats_teleop_twist_joy`

## 定位链路

实机定位链路在 `localization_launch.py` 中组织：

```text
livox_ros_driver2
  -> livox/lidar
  -> livox/imu
  -> point_lio/pointlio_mapping
  -> aft_mapped_to_init
  -> cloud_registered
  -> loam_interface
  -> odometry / registered_scan / lidar_odometry
```

`point_lio` 参数来自：

- 实机：`src/ats_sentry_bringup/params/node_params.yaml`
- 仿真：`src/ats_sentry_nav/ats_nav_bringup/config/simulation/nav2_params.yaml`

`small_gicp_relocalization` 负责将 PCD 地图和当前点云/里程计对齐，输出 `map -> odom` 相关定位信息。若 `launch_small_gicp_relocalization` 为 false，则 launch 会发布静态 `map -> odom`。

PCD 输入由 launch 参数 `prior_pcd_file` 指定。总入口默认使用：

```text
src/ats_sentry_bringup/pcd/<world>.pcd
```

PCD 不提交仓库。

## 地形链路

地形链路由 `terrain_analysis` 和 `terrain_analysis_ext` 组成：

```text
registered_scan + lidar_odometry
  -> terrain_analysis
  -> terrain_map
  -> terrain_analysis_ext
  -> terrain_map_ext
  -> traversability_grid
  -> traversability_height_diff_grid
  -> traversability_occupancy_ratio_grid
  -> traversability_ground_confidence_grid
  -> traversability_slope_grid
```

`terrain_analysis`：

- 订阅 `lidar_odometry`。
- 订阅 `registered_scan`。
- 发布 `terrain_map`。
- 通过滚动体素网格维护车体周围地形点云。

`terrain_analysis_ext`：

- 订阅扩展地形点云。
- 生成 `terrain_map_ext`。
- 生成 `OccupancyGrid` 形式的 traversability 语义栅格。
- 以高度差、占有率、地面置信度和坡度为核心语义。

关键参数在 `node_params.yaml` 与 `config/simulation/nav2_params.yaml` 中，包括：

- `traversabilityObstacleHeightThre`
- `traversabilitySafeHeightThre`
- `traversabilityOccupancyRatioThre`
- `traversabilityGroundConfidenceThre`
- `traversabilityHeightWeight`
- `traversabilityOccupancyWeight`
- `traversabilityGroundWeight`
- `traversabilityUnknownAsOccupied`
- `slopeGridMaxDeg`
- `useSlopeAsObstacle`

## Nav2 主链

`navigation_launch.py` 启动 Nav2 主链。生命周期节点包括：

- `controller_server`
- `smoother_server`
- `planner_server`
- `behavior_server`
- `bt_navigator`
- `waypoint_follower`
- `velocity_smoother`

实机参数中：

- `planner_server.GridBased.plugin` 使用 `nav2_smac_planner/SmacPlanner2D`。
- `smoother_server.bspline_smoother.plugin` 使用 `trajectory_optimizer/Nav2BSplineSmoother`。
- `controller_server.FollowPath.plugin` 使用 `nav2_mppi_controller::MPPIController`。
- `behavior_server.backup.plugin` 使用 `ats_nav2_behaviors/BackUpFreeSpace`。

仿真 loopback 参数中，planner 使用 `SmacPlannerHybrid`，其余主链同样包含 B-spline smoother、MPPI、恢复行为和速度治理。

## Nav2 插件

### `BackUpFreeSpace`

位置：

- `src/ats_sentry_nav/ats_nav2_plugins/src/behaviors/back_up_free_space.cpp`
- `src/ats_sentry_nav/ats_nav2_plugins/behavior_plugin.xml`

作用：

- 扩展 Nav2 backup 行为。
- 从 costmap 服务读取局部代价。
- 搜索可通行走廊。
- 支持 centroid fallback。
- 使用状态滞回、重规划冷却和速度平滑。
- 可发布 `back_up_free_space_markers`。

主要参数：

- `max_radius`
- `max_allowed_cost`
- `search_half_span_deg`
- `search_angle_increment_deg`
- `corridor_half_width`
- `dynamic_obstacle_prediction_enabled`
- `replanning_cooldown_s`
- `speed_filter_tau`
- `high_cost_speed_threshold`

### `IntensityVoxelLayer`

位置：

- `src/ats_sentry_nav/ats_nav2_plugins/src/layers/intensity_voxel_layer.cpp`
- `src/ats_sentry_nav/ats_nav2_plugins/costmap_plugins.xml`

作用：

- 在 costmap 中处理带 intensity 的 3D 点云。
- 按高度、强度、距离、自车 footprint 过滤点。
- 用 voxel grid 标记 costmap 障碍。
- 可发布 `voxel_grid`。

## 轨迹平滑与 ESDF

位置：

- `src/ats_sentry_nav/trajectory_optimizer`

核心能力：

- `Nav2BSplineSmoother`：作为 Nav2 smoother plugin 运行。
- `trajectory_optimizer_node`：旁路订阅 path，发布可视化平滑路径和轨迹 profile。
- `TrajectorySpeedGovernor`：根据轨迹 profile 对 `cmd_vel_controller` 做限速，输出 `cmd_vel_controller_governed`。
- ESDF provider：
  - `FakeCostmapEsdfProvider`
  - `TerrainPointCloudEsdfProvider`
  - `RcTraversabilityEsdfProvider`

当前参数中主线 `esdf_source` 为 `traversability_grid`。这表示 B-spline smoother 和旁路 optimizer 都优先使用 `traversability_grid` 及其语义侧图构造距离场。

轨迹 profile 消息类型为 `sp_msgs/msg/TrajectoryProfileMsg`，其中包含：

- 轨迹总长度
- 总时间
- 曲率代价
- 障碍代价
- 曲率
- 速度限制
- 速度
- 加速度

`trajectory_speed_governor` 订阅：

- `trajectory_profile`
- `cmd_vel_controller`

发布：

- `cmd_vel_controller_governed`
- `trajectory_profile_markers`

## 速度坐标转换

### `fake_vel_transform`

位置：

- `src/ats_sentry_nav/fake_vel_transform/src/fake_vel_transform.cpp`

作用：

- 订阅 Nav2 输出速度。
- 订阅 `cmd_spin`。
- 订阅 odom 和 local plan，同步获得当前 yaw。
- 发布 `gimbal_yaw_odom -> gimbal_yaw_fake` TF。
- 将速度旋转到中间坐标系。

实机参数中：

```text
input_cmd_vel_topic: cmd_vel_nav2_result
output_cmd_vel_topic: cmd_vel_gimbal_yaw_odom
robot_base_frame: gimbal_yaw_odom
fake_robot_base_frame: gimbal_yaw_fake
```

### `sentry_chassis_vel_transform`

位置：

- `src/ats_sentry_nav/sentry_chassis_vel_transform/src/chassis_vel_transform.cpp`

作用：

- 订阅 `serial/gimbal_joint_state` 或仿真中的 `joint_states`。
- 从 `gimbal_yaw_odom_joint` 读取大 yaw。
- 订阅 `cmd_vel_gimbal_yaw_odom`。
- 按大 yaw 旋转线速度。
- 限制速度、加速度和 yaw 变换速率。
- 输出 `/cmd_vel`。

该包已经归入 `src/ats_sentry_nav`，因为 fake yaw、云台大 yaw 和 Nav2 controller 输出链路都属于导航域。

## MINCO 规划骨架

位置：

- `src/ats_sentry_nav/minco_planner`

节点 `minco_planner`：

- 订阅 traversability / occupancy grid。
- 订阅 goal。
- 使用 A* 生成原始路径。
- 使用 MINCO 轨迹优化器生成参考轨迹。
- 使用 yaw planner 生成姿态。
- 使用 footprint safety checker 检查碰撞。
- 发布 raw path、reference path 和 debug marker。

该包当前更适合作为后续规划链路实验入口，不替代 Nav2 主链。
